# Portfolio Backend Projects

This workspace contains three Python portfolio projects built from resume-style descriptions and expanded into runnable, GitHub-ready mini applications.

## Projects

### 1. Global Store Expansion Platform

FastAPI service for onboarding country-specific stores with regional configuration, validation, audit logging, and lightweight operational metrics.

Path: `global-store-expansion-platform`

### 2. Localized Checkout and Payment Routing Simulator

FastAPI + Flask simulator for localized checkout routing with SQL-backed rule evaluation, fallback handling, and basic observability.

Path: `localized-checkout-payment-routing-simulator`

### 3. Product Information Extraction Pipeline

Pandas-based data pipeline that cleans noisy product feeds, extracts normalized attributes, and persists curated output into SQLite.

Path: `product-information-extraction-pipeline`

## Why These Work Well As Portfolio Projects

- Each project maps directly to a resume bullet but includes real code instead of only a claim.
- Each folder is structured to be published as its own repository.
- Every project includes documentation, runnable commands, and lightweight tests.
