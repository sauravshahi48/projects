# Your Company Document Assistant project

1. Install Python 3.11 or 3.12.
2. Open a terminal in this folder and follow the three Windows commands at the top of `README.md`.
3. Open http://127.0.0.1:8000 and click **Load sample documents**.
4. Ask about annual leave, then open the supporting PDF page.
5. Read `docs/INTERVIEW_GUIDE.md` and work through `docs/BUILD_PLAN.md` before adding the project to your resume.

The default runs without an API key and returns source passages. Optional semantic search and generated answers are explained in the README.

The full source code, sample PDFs, tests, evaluation fixtures/results, and learning notes are included. The package is ready to study, extend, and put into your own repository; it has not been published to a public website or GitHub account.
