# Prepare to explain the portfolio

## SourceDesk

Explain the distinction between retrieving relevant passages and generating an answer. The default is an offline retrieval baseline. Optional LangChain generation uses retrieved context and checks source labels and quotes; valid quotes do not guarantee that every claim is supported. Demonstrate PDF page links, duplicates, persistence and deletion. Add an independent question set before claiming general retrieval quality.

## QueueWise

Explain TF-IDF, logistic regression and the difference between a suggested class and an uncalibrated probability. The training examples are deliberately small and fictional. Demonstrate a billing ticket, a human correction and an unfamiliar topic routed to review. Measure a larger independent dataset before claiming real customer support performance. Draft replies are templates and are never sent automatically.

## RetentionLab

Explain the dummy baseline, average precision for an imbalanced target, and why the test set must not choose a model or threshold. Identical input vectors remain in one partition; exact raw duplicate rows are removed. A random grouped holdout is not a prospective validation across companies or time periods. Global feature importance does not explain an individual prediction or prove that a feature causes churn.

## Suggested demonstrations

1. Run each project and use the API documentation.
2. Reproduce its evaluation report and explain what the metrics do and do not measure.
3. Show one failure or uncertain example and how the interface handles it.
4. Make one improvement yourself and add a regression test for the behavior.

Describe these as personal projects. Use measured results and project scope, not invented employment experience, users, revenue, or savings. Be able to explain any assistance used to develop the code.
